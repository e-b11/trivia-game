# Trivia Game: React Typescript

## Project Description

This is currently a single player Trivia Game that allows the user to select a trivia difficulty, and then they are give ten questions for which they have ten seconds each to answer. At the end, the user will be given their score.

## How To Run

To run locally, clone the repository to your local machine. Navigate to the directory.
Then run `npm install` to add the necessary packages and `npm run dev` to start the server.

To see the static website, visit https://e-b11.github.io/trivia-game/

## API

This game uses the Open Trivia Database API to fetch a list of questions for the user to answer. Users can select what difficulty of question they would like to answer.

## Additional Features

The application uses a custom hook to fetch the trivia data and uses Material UI components/icons for styling.
